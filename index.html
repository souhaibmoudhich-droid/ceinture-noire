SYNCHRO

Comment obtenir le jeton
  1. Sur github.com : Settings → Developer settings → Personal access tokens → Tokens (classic).
  2. « Generate new token », coche seulement gist, expiration « No expiration ».
  3. Colle le même jeton sur chaque appareil (iPhone, iPad, ordi).

CALENDRIER

Ajouter au Calendrier de l'iPhone
  1. Copie le lien ci-dessus.
  2. Réglages → Apps → Calendrier → Comptes → Ajouter un compte → Autre → « Ajouter un calendrier avec abonnement ».
  3. Colle le lien. Le calendrier se met à jour tout seul. Sur Google Agenda : « Autres agendas » → « À partir de l'URL ».
